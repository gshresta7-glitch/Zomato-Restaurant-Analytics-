# Zomato-Restaurant-Analytics-
**Zomato Restaurant analytics dashboard using Power BI**
**Project Overview**

An interactive Power BI dashboard built to analyze Zomato restaurant data and generate insights into restaurant performance, customer ratings, online ordering, table booking, cuisines and location-wise trends.

**Objectives**
- Analyze restaurant ratings, votes, cuisines and location.
- Understand online ordering and table booking patterns.
- Create interactive dashboards to identify trends and business insights.

**Key KPIs**
- Total Restaurants:8,792
- Average Rating:3.70
- Total Votes: 14M
- Average Cost for two: ₹554

**Key Insights**
- BTM has the highest number of restaurants among the analyzed locations.
- North Indian cuisine is one of the most prevalent cuisine categories.
- Online ordering is available at a significant number of restaurants.
- Table booking is available at fewer restaurants compared with online ordering.
- Restaurant ratings and customer votes vary across different locations.
